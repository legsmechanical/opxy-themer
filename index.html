OP-XY Themer

Colour your OP-XY's screens.

Pick a hue for each knob, tint the greys, preview every screen, and download the files to copy onto your device. Nothing is uploaded: your files stay in this browser.

Made for OS 1.2.0. The app only changes screen files in /content/display, never the OS.

How do I get the display folder?
  1. Enable the dev menu once with Open-XY's builder or Ferret (browser MIDI, sets one flag).
  2. Enter te-boot: hold com while powering on.
  3. Choose 3. dev menu, then 2. mtp file transfer (mac) or 3. mtp file transfer (windows).
  4. Copy the folder content/display to your computer (on a Mac use an MTP app such as OpenMTP). Keep this copy: it is your backup.

The app checks every file against OS 1.2.0's stock files, so it works only from unmodified screens.

Put your theme on the OP-XY

  1. Unzip the download. display/ holds your themed screens; restore/display/ holds the stock versions of the same files, to undo.
  2. Enter te-boot (hold com while powering on) → 3. dev menu → mtp file transfer.
  3. Copy everything in display/ into content/display on the device, replacing the files there.
  4. Power off, then on.

To undo, copy restore/display/ the same way. If a screen ever fails to load, the same te-boot route still works, because the screens are only files.
